SSL-Certificate-Expiry-Monitor is a bulk TLS certificate expiry checker for domains supplied inline or via a text file. It dials each host concurrently with a configurable worker pool, extracts the leaf certificate's NotAfter and issuer, then renders a color-coded table (red under threshold, yellow near threshold, green otherwise) using fatih/color. A JSON output mode makes the results easy to feed into other pipelines, and an optional Discord webhook consolidates the endangered domains into a single alert message so on-call teams see one notification per run instead of one per domain.
